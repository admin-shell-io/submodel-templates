# Repo submodel-templates

This internet repository provides Submodel Templates (SMT) for Asset Administration Shell (AAS). For an overview confer the [AAS
Reading Guide](https://industrialdigitaltwin.org/wp-content/uploads/2022/12/2022-12-07_IDTA_AAS-Reading-Guide.pdf). For details of the meta model for AAS see [Specification of the Asset Administration Shell Part 1: Metamodel](https://industrialdigitaltwin.org/en/content-hub/aasspecifications).


## Submodel Templates Published by IDTA

The published folder contains Submodel Templates that are officially released and registered by IDTA.

## Submodel Templates Deprecated by IDTA

The deprecated folder contains Submodel Templates that have been deprecated by IDTA.
These templates remain valid for use but are no longer maintained, meaning that no further bug fixes, enhancements, or updates will be provided.

After six months from the publication of a new version of a Submodel Template (SMT), the previous version will be moved to the deprecated folder.

## Versions and Bug Fixes

Each version of a Submodel Template has its own folder `<SMT>/<major>/<minor>/`, for example `published/Digital nameplate/3/0/` for version 3.0.
A bug-fix release of that version is a sub-folder named after its bug-fix number, for example `published/Digital nameplate/3/0/2/` for version 3.0.2.

- Released files are never changed. A correction is published as a new bug-fix folder, so earlier releases stay available unchanged.
- A bug-fix release corrects the template files (JSON, AASX) of its version and, where needed, errors in the specification document. Its README lists the corrections and the issues it fixes.
- Use the newest bug-fix release of a version. The table below links it for every version.
- How bug fixes are prepared and checked is described in [tools/README.md](tools/README.md).

## Collaboration Mode

For the time being this repository is maintained by the IDTA office. In the future it is planned to allow pull request via CLA (contributor license agreement). 
Please use the issue tracker [submit a new issue](https://github.com/admin-shell-io/submodel-templates/issues/new) of this repository to provide feedback. 

## Submodel templates in development

The submodel currently under development is being managed by the IDTA. For any inquiries about the submodel's progress, please contact the [IDTA office](mailto:info@idtwin.org).
You can find the list of submodels under development at this link: [Link](https://industrialdigitaltwin.org/en/content-hub/submodels).
