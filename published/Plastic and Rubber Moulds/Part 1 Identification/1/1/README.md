## Plastic and Rubber Moulds - Part 1 Identification bug-fix version 1.1

This folder contains a bug-fix release of the submodel template artifacts.
It was produced from version 1 and contains corrections to the
machine-readable artifacts (JSON and AASX) and to the specification PDF.

### Artifacts in this directory

- JSON: IDTA 02038-1_Template_Plastic and Rubber Moulds-Identification.json
