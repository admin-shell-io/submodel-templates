## Digital nameplate bug-fix version 3.0.2

This folder contains a bug-fix release of the submodel template artifacts.
It was produced from version 3.0 and contains only corrections to the
machine-readable artifacts (JSON and AASX). The specification PDF, where present,
is carried over unchanged.

### Artifacts in this directory

- PDF: IDTA 02006-3-0-1_Submodel_Digital Nameplate.pdf (unchanged)
- AASX: IDTA 02006-3-0-2_Template_Digital Nameplate.aasx
- JSON: IDTA 02006-3-0-2_Template_Digital Nameplate.json
