## OPC UA Server Datasheet bug-fix version 1.1

machine-readable artifacts (JSON and AASX). The specification PDF, where present,
is carried over unchanged.

- JSON: IDTA 02009-1-0-Template-OPCUA-Server Datasheet.json
- PDF: IDTA 02009-1-0_Submodel_OPC UA Server Data Sheet.pdf (unchanged)
