## Hierarchical Structures enabling Bills of Material - Extension based on IEC 81346 bug-fix version 1.0.3

This folder contains a bug-fix release of the submodel template artifacts.
It builds on version 1.0.2, whose artifacts are unchanged.
The AASX packages are generated from the template JSON (tools/build_aasx.py).

- JSON: IDTA 02011-1-1-2 _Template_BoM_ExtensionbasedonIEC81346.json
- AASX: IDTA 02011-1-1-2 _Template_BoM_ExtensionbasedonIEC81346.aasx (AAS metamodel V3.0)
- AASX: IDTA 02011-1-1-2 _Template_BoM_ExtensionbasedonIEC81346_forAASMetamodelV3.1.aasx (AAS metamodel V3.1)
- PDF: [IDTA 02011-1_Submodel_BoM_Extension based on IEC 81346.pdf](../IDTA%2002011-1_Submodel_BoM_Extension%20based%20on%20IEC%2081346.pdf) (unchanged, not copied)
